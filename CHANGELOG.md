# Changelog

All notable public-facing changes to this repository should be recorded in this file.

The format is intentionally lightweight for now. Dates use `YYYY-MM-DD`.

## [0.3.0] - 2026-04-29

Initial public repository bootstrap for `ScenePack`.

Included in this snapshot:

- public-facing README rewrite for clearer product positioning
- bilingual onboarding improvements in the README
- public naming shift from `Peepaste` to `ScenePack` in user-facing copy
- product definition, PRD, architecture, and naming documents
- source prototype for capture, monitoring, title acceptance, and handoff generation
- optional tray UI prototype
- internal Windows packaging scripts

Known limits at this version:

- Python package and CLI still use the legacy compatibility name `peepaste`
- repository is public, but the product is still prototype-grade
- strongest workflow support is Windows + Snipaste-oriented desktop scenes
